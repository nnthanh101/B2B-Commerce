# Flow 09: Bulk Add to Cart

**Persona**: Buyer  
**Scenario**: A buyer quickly adds multiple products to cart using a bulk import interface.  
**Duration**: ~2 min

## Script (voice narration)

**[00:00]** "Bulk add speeds up shopping for large procurement teams. Instead of clicking item-by-item, buyers paste a list."

**[00:10]** "The buyer opens the bulk import interface and pastes their list from a supplier email: laptop-001 qty 3, monitor-dell qty 5, keyboard-logitech qty 10."

**[00:22]** "The system parses the list, matches each SKU to a product, and shows results: 3 items found, 0 unmatched."

(HOLD 1 second...)

**[00:30]** "The buyer reviews the parsed items and quantities, then clicks Add to Cart. All items land at once."

**[00:40]** "The cart now has 18 items. The buyer can adjust, remove, or proceed to quote request or checkout."

(HOLD 1 second...)

**[00:48]** "Bulk add is fast and accurate — perfect for procurement teams with standing orders."

**[00:54]** "Bulk add flow complete."
