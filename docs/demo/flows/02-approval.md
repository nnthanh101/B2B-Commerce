# Flow 02: Approval

**Persona**: Buyer (requester) + Admin (approver)  
**Scenario**: An admin reviews a pending quote request and approves or rejects the deal.  
**Duration**: ~2.5 min

## Script (voice narration)

**[00:00]** "An admin has logged into the approval dashboard. We see a pending quote request from the buyer we just watched."

**[00:09]** "The admin reviews the line items: laptop, monitor, keyboard. Total value is 1,132 euros, within budget and company policy."

(HOLD 1 second...)

**[00:16]** "The admin checks the company's approval settings. Admin sign-off is required. The admin now has two choices: approve or reject."

**[00:26]** "The admin clicks Approve. A comment field allows them to add context — for example, 'Standard equipment renewal for team.'"

(HOLD 2 seconds...)

**[00:36]** "The approval is submitted. The system updates the quote status to Approved and notifies the buyer that their request is cleared to proceed to checkout."

**[00:48]** "Approval complete. The buyer can now place the order knowing management has signed off."
