# Admin Persona

**Role**: Sales manager, company procurement administrator, or internal approver.

**Pain Points**:
- No visibility into which team members are spending, how much, and why
- Manual approval processes create delays (email back-and-forth)
- No audit trail of approval decisions
- Difficulty modifying orders after placement

**Platform Needs**:
- Dashboard showing pending quotes and approvals
- One-click approval or rejection with optional comments
- Company-level control over approval rules (who needs sign-off)
- Team member management (invite, set limits, assign roles)
- Edit orders post-placement for customer-requested changes

**Relevant Flows**:

| Flow | Title | Outcome |
|------|-------|---------|
| 02 | Approval | Admin reviews pending quote and approves/rejects with audit trail |
| 03 | Company Management | Admin controls team members, spending limits, and roles |
| 04 | Spending Limit Enforcement | System blocks overages; admin can override with trail |
| 05 | Quote Negotiation | Admin (as seller) exchanges terms with buyer |
| 08 | Order Edit | Admin modifies order post-placement; buyer notified |
| 11 | Invite Employee | Admin enrolls team members by email |
